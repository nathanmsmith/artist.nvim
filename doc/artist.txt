1. INTRODUCTION                                          *artist-introduction*

artist.nvim ports Artist from Emacs commit
f4f249a2249a7047ba41a659b8fcdcd7e1caf4e0. It supports Neovim 0.10+.
Coordinates are one-based display cells. Tabs, combining and wide characters,
virtual columns, and virtual rows are handled by a display-cell grid.

Previews use extmarks and do not edit the buffer. Completion commits one patch
as one undo step; cancellation leaves both the buffer and undo history intact.

==============================================================================
2. OPERATIONS                                              *artist-operations*

The 24 canonical operation names are:

pen                 pen_line               line
straight_line       rectangle              square
poly_line           straight_poly_line     ellipse
circle              text_see_through       text_overwrite
spray               spray_radius           erase_character
erase_rectangle     vaporize_line          vaporize_lines
cut_rectangle       cut_square             copy_rectangle
copy_square         paste                  flood_fill

Shift pairs are adjacent in the list above. `freehand`, `erase`, and common
hyphenated spellings are accepted as compatibility aliases.

==============================================================================
3. COMMANDS                                                  *artist-commands*

                                                        *:Artist*
:Artist [enable|disable|toggle|{operation}]
    Toggle the mode or select an operation.

                                                        *:ArtistTool*
:ArtistTool {operation}
    Select any canonical operation.

                                                        *:ArtistEnable*
                                                        *:ArtistDisable*
                                                        *:ArtistToggle*
:ArtistEnable | :ArtistDisable | :ArtistToggle
    Manage Artist mode in the current buffer.

                                                        *:ArtistShift*
:ArtistShift
    Select the shifted variant of the current operation.

                                                        *:ArtistPicker*
:ArtistPicker
    Select an operation through `vim.ui.select()`.

                                                        *:ArtistArrow*
:ArtistArrow {first|second}
    Toggle an arrow on that endpoint for line operations.

                                                        *:ArtistSet*
:ArtistSet {setting} {value}
    Change a setting in the current buffer-local session. Character settings
    accept `none` or `default` to reset them.

==============================================================================
4. MAPPINGS                                                  *artist-mappings*

    <LeftMouse>/<LeftDrag>/<LeftRelease>       mouse operation
    <S-LeftMouse>/<S-LeftDrag>/<S-LeftRelease> shifted operation
    <MiddleMouse>, <RightMouse>                 operation picker
    <CR>                                       set/apply a point
    counted <CR>, <C-CR>                       finish a poly-line
    h j k l, arrow keys                        move and draw/preview
    C-b C-n C-p C-f                           Emacs movement equivalents
    < / >                                      toggle endpoint arrows
    C-c C-a {key}                              upstream operation/settings map
    <C-c>                                      cancel

Mappings are buffer-local and displaced mappings are restored. Set
`mappings = false` to install none, or `mouse_wheel = true` to map the wheel
to operation cycling.

==============================================================================
5. CONFIGURATION                                        *artist-configuration*

Setup is optional: >lua

  require("artist").setup({
    tool = "pen_line",
    aspect_ratio = 1,
    rubber_banding = true,
    first_character = "1",
    second_character = "2",
    line_character = nil,
    fill_character = nil,
    default_fill_character = ".",
    erase_character = " ",
    trim_line_endings = true,
    borderless_shapes = false,
    first_arrow = false,
    second_arrow = false,
    ellipse_left_character = "(",
    ellipse_right_character = ")",
    flood_fill_right_boundary = "window_width",
    fill_column = 80,
    flood_fill_incremental = false,
    vaporize_fuzziness = 1,
    spray_interval = 0.2,
    spray_radius = 4,
    spray_characters = { " ", ".", "-", "+", "m", "%", "*", "#" },
    spray_initial_character = ".",
    timer_factory = nil,
    text_renderer = nil,
    figlet_executable = "figlet",
    figlet_font = "standard",
    rectangle_register = '"',
    mappings = true,
    mouse_wheel = false,
    winbar = true,
    transparent_selection = true,
  })
<
`text_renderer` receives `(text, options)` and returns a string or list of
lines. Figlet is optional. `rectangle_register = false` disables blockwise
register interoperation. Flood filling always computes and commits one atomic
patch; the incremental-display option exists for configuration compatibility.

==============================================================================
6. LUA API                                                      *artist-api*

enable([{bufnr}], [{options}])                          *artist.enable()*
disable([{bufnr}])                                     *artist.disable()*
toggle([{bufnr}], [{options}])                          *artist.toggle()*
is_enabled([{bufnr}])                               *artist.is_enabled()*
    Manage or query a buffer-local session.

set_tool({operation}, [{bufnr}])                       *artist.set_tool()*
get_tool([{bufnr}])                                    *artist.get_tool()*
shift_tool([{bufnr}])                                *artist.shift_tool()*
toggle_arrow({first|second}, [{bufnr}])             *artist.toggle_arrow()*
    Select operations and arrow state.

finish([{bufnr}])                                      *artist.finish()*
cancel([{bufnr}])                                      *artist.cancel()*
    Finish a poly operation or discard pending state.

draw({operation}, {from}, [{to}], [{options}])            *artist.draw()*
    Execute an atomic operation without enabling the interactive mode.
    Positions are `{ row, col }` or `{ row, col }` arrays in display cells.

ArtistEnabled, ArtistDisabled, and ArtistToolChanged are `User` events.

==============================================================================
NEOVIM DIVERGENCES                                      *artist-divergences*

Extmarks replace buffer-mutating rubber banding; a blockwise register replaces
rect.el; the winbar and vim.ui.select replace Emacs UI integrations. Picture
mode and X pointer shapes are not applicable to Neovim.
